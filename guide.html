ตั้งชื่อว่า Dek70

  1. แตะชื่อ Untitled Script ด้านบน
  2. ลบชื่อเดิม พิมพ์ Dek70
  3. กด Rename
  4. กด Done มุมซ้ายบน

ขั้นที่ 6 จาก 8

กดค้างที่หน้าจอโฮม แล้วกด Add Widget

  1. กดค้างที่ว่างบนหน้าจอโฮมจนไอคอนสั่น
  2. กด Edit มุมซ้ายบน
  3. กด Add Widget

ต้องเห็น หน้ารวม Widget มีช่อง Search Widgets ด้านบน

ขั้นที่ 7 จาก 8

ค้นหา Scriptable แล้วกด Add Widget

  1. พิมพ์ Scriptable ในช่องค้นหา แล้วแตะชื่อแอป
  2. ปัดซ้ายถ้าอยากได้ขนาด Medium
  3. กด Add Widget
  4. กด Done มุมขวาบน

ต้องเห็น กล่องสีเทาเขียนว่า Configure widget อยู่บนหน้าจอโฮม

ขั้นที่ 8 จาก 8

  1. กดค้างที่กล่องนั้น แล้วกด Edit Widget
  2. แตะ Choose ที่แถว Script
  3. เลือก Dek70
  4. แตะที่ว่างนอกกล่องเพื่อปิด

ต้องเห็น Widget นับถอยหลังขึ้นแล้ว
