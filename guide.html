🐻 ติดตั้ง Dek70 Countdown

ทำตามทีละขั้น ดูภาพแล้วกดตาม

  • iPhone หรือ iPad
  • ต่อเน็ตอยู่
  • ใช้เวลาประมาณ 2 นาที
  • Android ยังใช้ไม่ได้
  1. 1

    โหลดแอป Scriptable

    แอปฟรีจาก App Store

    เปิด App Store

    ต้องเห็น ไอคอน Scriptable อยู่บนเครื่อง

  2. 2

    ก๊อปโค้ด

    กดปุ่มนี้ครั้งเดียว

    ต้องเห็น ปุ่มเปลี่ยนเป็น “ก๊อปแล้ว ✓”

  3. 3

    เปิด Scriptable แล้วกด +

    ปุ่ม + อยู่มุมขวาบน

    ต้องเห็น หน้าว่าง ชื่อด้านบนเขียนว่า Untitled Script

  4. 4

    แตะค้าง แล้วกด Paste

    แตะค้างที่ว่างบนหน้าจอ 1 วินาที แล้วกด Paste

    ต้องเห็น โค้ดขึ้นเต็มหน้า

  5. 5

    ตั้งชื่อว่า Dek70

    1. แตะชื่อ Untitled Script ด้านบน
    2. ลบชื่อเดิม พิมพ์ Dek70
    3. กด Rename
    4. กด Done มุมซ้ายบน

    ต้องเห็น การ์ดชื่อ Dek70 อยู่ในรายการ

  6. 6

    กดค้างที่หน้าจอโฮม แล้วกด Add Widget

    1. กดค้างที่ว่างบนหน้าจอโฮมจนไอคอนสั่น
    2. กด Edit มุมซ้ายบน
    3. กด Add Widget

    ต้องเห็น หน้ารวม Widget มีช่อง Search Widgets ด้านบน

  7. 7

    ค้นหา Scriptable แล้วกด Add Widget

    1. พิมพ์ Scriptable ในช่องค้นหา แล้วแตะชื่อแอป
    2. ปัดซ้ายถ้าอยากได้ขนาด Medium
    3. กด Add Widget
    4. กด Done มุมขวาบน

    ต้องเห็น กล่องสีเทาเขียนว่า Configure widget อยู่บนหน้าจอโฮม

  8. 8

    เลือกสคริปต์ Dek70

    1. กดค้างที่กล่องนั้น แล้วกด Edit Widget
    2. แตะ Choose ที่แถว Script
    3. เลือก Dek70
    4. แตะที่ว่างนอกกล่องเพื่อปิด

    ต้องเห็น Widget นับถอยหลังขึ้นแล้ว

  9. เสร็จแล้ว 🎉

    Widget จะอัปเดตวันให้เองทุกชั่วโมง ไม่ต้องทำอะไรอีก
