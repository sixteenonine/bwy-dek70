5
ขั้นที่ 5 จาก 7
ตั้งชื่อว่า Dek70

    
  1. แตะชื่อ Untitled Script ด้านบน
  2. ลบชื่อเดิม พิมพ์ Dek70
  3. กด Rename
  4. กด Done มุมซ้ายบน

    
    
ต้องเห็น การ์ดชื่อ Dek70 อยู่ในรายการ

  

  

    
6
ขั้นที่ 6 จาก 7
เพิ่ม Widget บนหน้าจอโฮม

    
  1. กดค้างที่ว่างบนหน้าจอโฮมจนไอคอนสั่น
  2. กด Edit มุมซ้ายบน แล้วกด Add Widget
  3. พิมพ์ Scriptable ในช่องค้นหา แล้วแตะชื่อแอป
  4. กด Add Widget (ปัดซ้ายก่อนถ้าอยากได้ขนาด Medium)
  5. กด Done มุมขวาบน

    
    
ต้องเห็น กล่องสีเทาเขียนว่า Configure widget อยู่บนหน้าจอโฮม

  

  

    
7
ขั้นที่ 7 จาก 7
เลือกสคริปต์ Dek70

    
  1. กดค้างที่กล่องนั้น แล้วกด Edit Widget
  2. แตะ Choose ที่แถว Script
  3. เลือก Dek70
  4. แตะที่ว่างนอกกล่องเพื่อปิด

    
    
ต้องเห็น Widget แสดงผลนับถอยหลังแล้ว
