ติดตั้งใน 1 นาที

  1. โหลดแอป Scriptable

    แอปฟรี ใช้สร้าง widget บน iPhone และ iPad

    เปิด App Store
  2. ก๊อปโค้ด

    กดปุ่มเดียว โค้ดจะถูกก๊อปไว้ให้เลย

  3. วางใน Scriptable

    เปิดแอป กดปุ่ม + มุมขวาบน วางโค้ด ตั้งชื่อว่า Dek70 แล้วกด Done

  4. เพิ่ม widget

    กดค้างที่หน้าจอโฮม เลือกเพิ่ม widget ค้นหา Scriptable เลือกขนาด แล้วกดค้างที่ widget เลือก Edit Widget ตรง Script เลือก Dek70

คำถามที่เจอบ่อย

ต้องอัปเดตเองไหม

ไม่ต้อง ติดตั้งครั้งเดียวจบ ถ้า ทปอ. เลื่อนวัน widget จะเปลี่ยนตามให้เอง

ทำไมตัวเลขยังไม่เปลี่ยน

iPhone รีเฟรช widget เองประมาณชั่วโมงละครั้ง ถ้าอยากให้เปลี่ยนทันที เปิดแอป Scriptable แล้วกดรัน Dek70 หนึ่งรอบ

ขึ้นว่า Unsupported widget หรือเป็นกล่องว่าง

กดค้างที่ widget เลือก Edit Widget แล้วเช็กว่าตรง Script เลือก Dek70 อยู่

ขึ้นว่า "ต่อเน็ตแล้วเปิดใหม่อีกครั้งนะ"

ครั้งแรกต้องมีเน็ตเพื่อโหลด widget ต่อเน็ตแล้วเปิดแอป Scriptable รัน Dek70 หนึ่งรอบ หลังจากนั้นไม่มีเน็ตก็ยังใช้ได้

กินแบตหรือเก็บข้อมูลอะไรไหม

ไม่กินแบต เพราะทำงานแค่ตอน iPhone รีเฟรช widget และไม่เก็บข้อมูลส่วนตัวใดๆ
